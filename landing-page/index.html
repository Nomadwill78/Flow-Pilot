How it works

Four steps, running entirely in the user's own session

FlowPilot reads the page as structured text rather than screenshots. That makes it fast, cheap, and accurate on the dense B2B interfaces where vision models struggle most.

Read the page

Every visible control is captured with its accessible label and a stable reference — no screenshots, no vision tokens.

Ask the model

Your proxy adds the workflow prompt and calls your LLM. The API key never leaves your server.

Check the guardrails

Every proposed action is validated against your policy before it touches the DOM. Protected controls are refused outright.

Perform the action

Native browser events drive React, Vue and Angular correctly — then the loop repeats against the updated page.

FAQ

The questions buyers actually ask

Can it do something destructive by mistake?

Not to anything you protect. Any control marked data-fp-block is refused outright, and controls marked data-fp-confirm — including every submit button by default — require the user to approve in the chat panel first. Password and payment fields are refused at the library level regardless of configuration, and every check runs again on the server.

What if the page tries to manipulate the AI?

Page content is wrapped in explicit untrusted-content markers and the system prompt instructs the model to ignore instructions found there. More importantly, the guardrails do not consult the model at all: a blocked control stays blocked even if the model is fully convinced it should click it.

Does it need access to our backend or database?

No. It runs in the browser and can only do what the signed-in user could already do by clicking. That is usually the fastest path through a security review — there is no new data path and no new set of credentials.

Which AI model does it use?

Whichever you choose. The proxy speaks both the Anthropic Messages API and the OpenAI Chat Completions shape, which covers OpenAI, Google, Groq, Together, OpenRouter, Alibaba DashScope, and local models via Ollama or vLLM. Changing provider is an environment variable, not a code change.

How long does integration actually take?

The widget itself is four lines. A realistic first deployment — proxy deployed, auth wired to your existing sessions, one workflow tuned to your screens — is a day for a competent front-end developer. Adding accessible labels to unlabelled buttons is usually the only real work, and it improves your accessibility score anyway.

What does it cost to run?

Because FlowPilot sends structured text instead of screenshots, a typical turn is a few thousand tokens rather than the tens of thousands a vision-based agent needs. You control the ceiling directly through per-user rate limits and the maximum steps per request.
