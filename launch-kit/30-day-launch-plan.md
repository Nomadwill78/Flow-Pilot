# FlowPilot — 30-Day Launch Plan

## Week 1: Foundation (Days 1-7)

### Day 1: Deploy
- [ ] Deploy landing page to Vercel
- [ ] Deploy demo page to Vercel
- [ ] Deploy server to Railway/Render
- [ ] Point custom domain (optional)
- [ ] Set up SSL/HTTPS

### Day 2: Payments & Analytics
- [ ] Create Stripe account
- [ ] Set up Stripe products/prices (Starter $49, Business $149)
- [ ] Add Stripe checkout to landing page
- [ ] Set up Google Analytics or Plausible
- [ ] Set up UptimeRobot for server monitoring

### Day 3: Email & Communication
- [ ] Create business email (hello@flowpilot.dev)
- [ ] Set up Resend or SendGrid
- [ ] Create email templates in your ESP
- [ ] Set up Calendly for demo bookings

### Day 4: Social Presence
- [ ] Create Twitter/X account (@flowpilot)
- [ ] Create LinkedIn company page
- [ ] Create GitHub organization
- [ ] Add profile pictures, bios, links
- [ ] Pin launch tweet/post

### Day 5: Content Creation
- [ ] Record 2-minute demo video (Loom/Screen Studio)
- [ ] Write "How We Built FlowPilot" blog post
- [ ] Create 5 social media graphics (Canva)
- [ ] Write Product Hunt listing copy

### Day 6: Outreach Prep
- [ ] Build prospect list (50 SaaS founders)
- [ ] Research each prospect's app and pain points
- [ ] Personalize email templates
- [ ] Set up email tracking (Hunter, Mailtrack)

### Day 7: Soft Launch
- [ ] Share with friends and network
- [ ] Post on personal social accounts
- [ ] Get 5-10 beta testers
- [ ] Collect initial feedback
- [ ] Fix any critical bugs

## EMERGENCY CONTACTS

If something breaks during launch:
- Server down → Check Railway/Render dashboard → Restart service
- Landing page down → Check Vercel → Redeploy
- Payment issues → Check Stripe dashboard → Test checkout flow
- LLM errors → Check API key → Verify rate limits
