# FlowPilot — Pitch One-Pager

---

## THE PROBLEM

**SaaS dashboards are graveyards of unused features.**

Companies spend months building powerful tools — advanced filters, multi-step workflows, reporting dashboards. But users open the app, get overwhelmed, and either:
- Open a "how do I...?" support ticket ($15-50 each)
- Abandon onboarding (20-40% drop-off)
- Churn entirely

**The result:** Engineering effort wasted. Support costs balloon. Revenue leaks.

---

## THE SOLUTION

**FlowPilot — AI Copilot for Web Apps**

An embeddable AI assistant that lets users control any web interface through natural language.

**"Show me pending orders" → FlowPilot clicks, filters, and finds them.**
**"Export last month's report" → FlowPilot navigates, applies filters, downloads CSV.**

Unlike chatbots that just answer questions, FlowPilot **performs actions**.

---

## HOW IT WORKS

```
User types command → AI reads DOM → LLM reasons → 
Native events dispatched → Task completed → User confirmed
```

1. **Embeds** as a JavaScript widget in your app
2. **Reads** the live DOM as structured text
3. **Reasons** with your chosen LLM (OpenAI, Claude, Gemini, local)
4. **Executes** native browser events (click, input, scroll, select)
5. **Secures** all API calls behind your proxy server

**Integration time: Under 1 hour.**
